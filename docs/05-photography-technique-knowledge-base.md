# 摄影技巧知识库 v0.1

> 用途：为“摄影作品专业分析 Agent”沉淀可复用的摄影技巧细分项，后续用于生成更专业的诊断建议、建议优先级、以及“基于建议的对比图”。
>
> 生成原则：基于专业摄影书籍和出版社/作者公开介绍归纳，不摘抄原文；每个条目尽量能落到“可观察信号 -> 建议 -> 对比图呈现”。

## 参考书目与来源范围

- Bryan Peterson, *Understanding Exposure*：曝光三要素、景深、冻结/模糊动作、低光和夜景、包围曝光、滤镜等基础与创意曝光主题。
- Fil Hunter, Steven Biver, Paul Fuqua, Robin Reid, *Light--Science & Magic*：光的性质、反射、明暗、布光控制、材质表现和实用灯光理论。
- Michael Freeman, *The Photographer's Eye / Graphic Guide*：构图、图形秩序、视觉设计、画面组织。
- Ansel Adams, *The Camera*, *The Negative*, *The Print*：相机、镜头、曝光、影调控制、分区系统、从拍摄到成片的技术链路。
- Bruce Barnbaum, *The Art of Photography*：技术服务于表达、个人意图、数字分区系统、影调和创作判断。
- Scott Kelby, *The Digital Photography Book*：常见题材的实操型拍摄技巧、设备使用和数字摄影工作流。

## 条目结构

- `id`：稳定编号，后续可映射到规则引擎或 UI 标签。
- `技巧项`：摄影知识点。
- `可诊断信号`：前端可从图片、CV、EXIF、模型标签或用户输入中观察到的迹象。
- `建议方向`：给用户的建议应该围绕什么讲。
- `对比图候选`：未来生成“建议前/建议后”时可以呈现的视觉变化。

## J. 诊断结果到“建议对比图”的映射

| 问题类型 | 触发信号 | 对比图类型 | 生成策略 |
|---|---|---|---|
| 主体不突出 | 主体小、背景高对比、模型主体置信度低 | 构图裁切对比 | 左图原图，右图建议裁切；叠加三分线和主体框 |
| 曝光偏暗 | 平均亮度低、主体暗、直方图偏左 | 曝光/阴影对比 | 右图提升曝光或阴影，保留高光警示 |
| 高光溢出 | 大面积接近 255 | 高光恢复对比 | 右图降低高光，标出不可恢复区域 |
| 色温偏移 | 白平衡估计异常、肤色偏色 | 白平衡对比 | 冷暖滑杆 + 中性区域标记 |
| 背景杂乱 | 边缘高频、高饱和杂色、主体边缘低分离 | 背景弱化对比 | 右图降背景饱和/亮度/清晰度 |
| 构图歪斜 | 水平线/垂直线角度异常 | 几何校正对比 | 右图旋转/透视校正并保留网格 |
| 清晰度不足 | 梯度/拉普拉斯清晰度低 | 锐化或拍摄建议对比 | 后期轻锐化预览 + 标注可能是拍摄端问题 |
| 噪声明显 | 暗部噪声/高 ISO | 降噪对比 | 右图降噪但标出细节损失风险 |
| 动作不完整 | 人物/运动标签 + 快门慢/主体虚 | 快门策略示意 | 不伪造瞬间，给参数建议和运动方向示意 |
| 光线平 | 明暗对比低、主体体积弱 | 光线方向示意 | 叠加主光/补光箭头，不直接改图或只做轻微明暗模拟 |

## M. v0.2 建议话术模板

> 话术目标：少说“好/不好”，多说“为什么、怎么改、优先级、是否适合做对比图”。建议结果应保持克制，避免假装能从一张图推断拍摄者无法控制的信息。

| 场景 | 建议模板 | 使用条件 | 注意事项 |
|---|---|---|---|
| 主体不明确 | “这张图最需要先解决的是观看入口。当前观众容易先看到 {干扰区域}，建议通过 {裁切/压暗/降低饱和/虚化背景} 把注意力拉回 {主体}。” | 主体检测弱、背景高对比、边缘干扰多 | 不要直接说“没有主题”，改说“观看入口不够明确” |
| 曝光偏暗 | “主体所在的中间调偏低，影响细节阅读。建议先提升主体局部亮度，再检查高光是否保留纹理。” | 平均亮度低、主体暗、暗部细节弱 | 区分低调风格和欠曝 |
| 高光过曝 | “画面最亮区域已经接近无纹理白，后期恢复空间有限。下次拍摄可以优先保护高光，必要时使用曝光补偿或包围曝光。” | 高亮像素占比高 | 不承诺能恢复已丢失细节 |
| 清晰度不足 | “清晰度问题更像拍摄端造成，而不只是后期锐化不足。建议优先检查快门速度、对焦点和手持稳定。” | 全图模糊或主体运动模糊 | 不要用锐化掩盖严重失焦 |
| 构图拥挤 | “画面信息密度偏高，主体周围缺少呼吸空间。建议先做边缘清理，再尝试更紧或更宽的二选一裁切。” | 边缘干扰、主体贴边 | 给出具体裁切方向 |
| 光线平 | “当前光线均匀但立体感弱。建议寻找侧光或侧逆光，让主体轮廓、纹理和空间层次更清楚。” | 低反差、主体体积弱 | 阴天/柔光题材要温和处理 |
| 色彩杂乱 | “色彩不是越多越好。建议保留一个主色和一个强调色，把其他干扰色降饱和或压暗。” | 高饱和颜色数量多 | 不要全局去饱和导致灰 |
| 背景抢眼 | “背景的亮度或色彩权重高于主体。建议降低背景亮度/饱和度，或拍摄时移动机位让主体落在更干净的背景上。” | 背景高亮/高饱和/高频 | 优先建议拍摄端移动机位 |
| 人像眼神弱 | “人像优先级通常是眼睛和表情。建议确认眼睛清晰、有眼神光，并避免背景线条穿过头部。” | 人脸/人像标签、眼部区域暗或软 | 不做外貌评价 |
| 产品质感弱 | “产品图的关键是轮廓、材质和品牌识别。建议增加侧向渐变高光，并让背景明度与产品边缘分离。” | 产品/静物标签 | 避免不真实改变产品颜色 |

## N. v0.2 置信度计算策略

| 置信度 | 条件 | 推荐输出方式 | 示例 |
|---|---|---|---|
| 高 | 至少两个独立信号一致，例如 EXIF 快门慢 + CV 模糊，或高光像素占比高 + 主体亮部无纹理 | 给明确建议和可选对比图 | “优先提高快门或使用稳定支撑” |
| 中 | 一个强信号或多个弱信号，但题材/主体识别不完全确定 | 给建议并说明判断依据 | “看起来更像背景干扰，建议先尝试裁切” |
| 低 | 只有模型标签或单一视觉猜测，缺少 CV/EXIF 支撑 | 用探索式建议，不生成强结论 | “可以尝试，但需要结合拍摄意图确认” |
| 冲突 | 技术指标显示问题，但风格可能有意为之 | 同时给“保留风格”和“技术修正”两条路径 | 低调照片、故意拖影、柔焦人像 |

建议置信度可以由以下信号加权：

- `cv`：曝光均值、亮度分布、局部对比、清晰度、边缘高频、色彩数量、主体/背景分离。
- `exif`：焦距、光圈、快门、ISO、曝光补偿、拍摄时间、是否有闪光信息。
- `vision`：人像、风光、建筑、产品、食物、运动、夜景、动物等场景标签。
- `layout`：主体位置、边缘干扰、水平线、三分线靠近度、负空间比例。
- `userIntent`：用户选择的目标，例如“更通透”“更电影感”“更适合发布”“更专业商业图”。

## T. v0.3 对比图流水线

| 步骤 | 输入 | 输出 | 说明 |

## W. v0.3 反例与保守原则

| 情况 | 不应直接判错 | 更好的说法 |
|---|---|---|
| 低调照片暗部多 | 可能是风格 | “如果你想保留低调氛围，建议只提亮关键主体边缘。” |
| 高调照片亮部多 | 可能是风格 | “高调成立的前提是主体轮廓和关键细节仍可读。” |
| 故意拖影 | 可能表现速度 | “拖影可以保留，但需要让主体方向和节奏更明确。” |
| 柔焦人像 | 可能是梦幻风格 | “柔和风格可以成立，但眼神最好仍有清晰锚点。” |
| 眩光和漏光 | 可能是氛围 | “保留眩光时，建议避免它盖过主体表情或关键纹理。” |
| 强色偏 | 可能是创意调色 | “如果这是风格化色彩，需要保护肤色或产品识别。” |
| 中心构图 | 不是天然错误 | “中心构图需要对称、凝视或强图形秩序支撑。” |
| 大面积留白 | 不是空 | “留白最好服务方向、情绪或文字空间。” |
| 背景虚化不足 | 不一定要虚化 | “环境有故事时可以保留清晰背景，但要控制干扰。” |
| 后期移除杂物 | 纪实题材要谨慎 | “纪实类建议用裁切和等待替代内容删除。” |

评估指标：

- `建议命中率`：用户认为建议确实对应照片主要问题的比例。
- `建议可执行率`：用户知道下一步怎么做的比例。
- `对比图可信度`：用户认为对比图没有过度或误导的比例。
- `误判率`：把创作选择判为错误的比例，应重点降低。
- `重复率`：同一问题被多条建议重复表达的比例。
- `题材适配度`：不同题材下权重和建议是否符合摄影常识。

## AP. v0.5 数据迁移步骤

1. 从 Markdown 表格中抽取 `id`、`技巧项`、`可诊断信号`、`建议方向`、`对比图候选`。
2. 给每个 `id` 自动归类到 `TechniqueCategory`。
3. 将 `对比图候选` 映射为 `CompareType`。
4. 人工补充 `shortExplanation` 和 `sourceThemes`。
5. 把 `S. 诊断信号字典` 转成 `SignalConfig[]`。
6. 把 `X3. 规则编号表` 转成 `RuleConfig[]`。
7. 为每条规则写 2-3 个测试 fixture。
8. 用测试图片跑规则，人工标注“命中/误判/漏判”。
9. 根据误判调整阈值和题材权重。
10. 最后再接入 UI 的对比图组件。

## AQ. v0.5 质量门禁

| 门禁 | 通过标准 | 不通过时处理 |
|---|---|---|
| 规则可解释 | 每条建议至少有 1 个可展示证据 | 降级为探索式建议 |
| 对比图安全 | 不伪造事实、不承诺不可恢复修复 | 改为标注图或参数卡 |
| 题材匹配 | 题材权重影响排序 | 要求用户手动选择题材 |
| 文案克制 | 不出现羞辱性、绝对化表达 | 使用模板重写 |
| 用户可执行 | 至少包含一个拍摄动作或后期动作 | 补充 checklist |
| 风格尊重 | 风格冲突时提供双路径 | 展示风格保留开关 |
| 色准保护 | 产品/商业默认锁色 | 禁止强色彩预览 |
| 肤色保护 | 人像默认保护肤色 | 限制全局色偏 |
